# ☁️ Cloud & DevOps — CETPA Summer Training

A collection of **Cloud & DevOps hands-on projects and practical implementations** completed during my CETPA Summer Training.

This repository contains practical work covering **Microsoft Azure, Virtual Machines, Azure Storage, Networking, Load Balancing, IAM/RBAC, Linux, and File Sharing**.

---

## 🚀 Projects

### ☁️ Microsoft Azure

| # | Project                                                                                    | Description                                                                                                             |
| - | ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| 1 | [Azure Activity Logs](./azure_activity_logs)                                               | Documentation and practical work related to Azure activity logs, system activity monitoring, and failed login tracking. |
| 2 | [Azure VM Deployment](./azure_vm_Deployment)                                               | Deployment and configuration of Virtual Machines in Microsoft Azure.                                                    |
| 3 | [Azure IAM & RBAC Setup](./azure-iam-rbac_setup)                                           | Implementation of Identity and Access Management using Azure Role-Based Access Control (RBAC).                          |
| 4 | [Azure Storage Disk Attachment](./azure-storage-disk-attachment)                           | Creating, attaching, and managing storage disks with Azure Virtual Machines.                                            |
| 5 | [Azure Public Load Balancer](./azure-public-load-balancer)                                 | Configuration of an external/public Azure Load Balancer for distributing traffic across virtual machines.               |
| 6 | [Azure Internal Load Balancer](./azure-internal-load-balancer)                             | Configuration of an internal load balancer for distributing traffic within a private network.                           |
| 7 | [Azure Inter-VM File Sharing](./azure-inter-vm-file-sharing)                               | File sharing and data transfer between Azure Virtual Machines.                                                          |
| 8 | [Azure Disk Partitioning & Volume Management](./azure-disk-partitioning-volume-management) | Disk partitioning, volume creation, and storage management in an Azure VM environment.                                  |
